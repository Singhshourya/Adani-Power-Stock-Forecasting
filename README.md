# Adani-Power-Stock-Forecasting

A time-series forecasting project using Python and Facebook Prophet to analyze Adani
Power closing prices and forecast future values.

## Project files

- `Adani_Power_Stock_Forecasting.ipynb` — loads the data, trains the Prophet model,
  and plots a 30-day forecast.
- `Adani_Power_Historical_Data.csv` — input data with `Date` and `Close` columns.
- `requirements.txt` — Python dependencies for running the notebook.

Install the dependencies and start Jupyter from the project directory:

```bash
python -m pip install -r requirements.txt
jupyter notebook Adani_Power_Stock_Forecasting.ipynb
```
